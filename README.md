An original short poem about a mother who switches off a co-parenting algorithm and lets her daughter choose where to go.

The entry is an offline Node 22 program that writes the poem to `entry.txt` in the configured output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## Test

```sh
node tests/smoke.mjs
```
